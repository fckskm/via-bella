# VIA BELLA — European Travel Collection

Премиальная туристическая платформа по Европе: журнальный дизайн + рабочий сервис бронирования.
Коллективный курсовой проект ПМ.05 «Разработка сервиса бронирования экскурсий и туров».

**Стек:** PHP 8.3+, Laravel 13, Blade, чистые CSS/JS (без сборки), реляционная БД
(SQLite по умолчанию для запуска «из коробки»; MySQL 8.4 — см. ниже).

## Запуск

```bash
composer install
cp .env.example .env && php artisan key:generate
touch database/database.sqlite          # для SQLite
php artisan migrate:fresh --seed
php artisan serve                        # http://127.0.0.1:8000
php artisan test                         # 11 автотестов
```

Для MySQL в `.env`: `DB_CONNECTION=mysql`, `DB_HOST`, `DB_DATABASE`, `DB_USERNAME`, `DB_PASSWORD` — миграции переносимы.

Демо-аккаунты: `admin@viabella.test / Admin12345` (администратор), `demo@viabella.test / Demo12345` (пользователь).

## Что реально работает (обязательные функции курсовой)
- **Каталог туров** (F-01, F-10): поиск, фильтры (страна, настроение, формат, тема, бюджет, дата, гости), сортировка.
- **Тур и гиды** (F-02–F-04): страница-«материал журнала», программа, расписание со свободными местами; профили гидов.
- **Бронирование** (F-05, F-06): пошаговый мастер; проверка мест **на сервере** в транзакции с блокировкой сеанса — превышение вместимости невозможно (см. тесты).
- **Отзывы** (F-08): только автор завершённой поездки, один раз, оценка 1–5.
- **Личный кабинет** (F-07, F-11): регистрация, вход, профиль, смена пароля, бронирования, история, избранное, рекомендации по интересам.
- **Админ-панель** (F-09, `/admin`): туры, гиды, расписание, бронирования, отзывы. Тур с бронированиями архивируется, а не удаляется.
- Пароли — только bcrypt-хеши; серверная валидация; роли `user` / `admin`; CSRF; throttle на вход.

## Демонстрационные разделы (без внешних интеграций)
Авиабилеты, отели, конструктор путешествия и онлайн-консультант работают на демо-данных / правилах и везде помечены как примеры. Покупок и подтверждённых броней они не создают; консультант — не ИИ.

## База данных
`users`, `guides`, `tours`, `schedules`, `bookings`, `reviews` (+ служебная `favorites`) — внешние ключи, `restrict`/`cascade` по смыслу, 3НФ; цена на момент брони хранится в `bookings.unit_price`.
